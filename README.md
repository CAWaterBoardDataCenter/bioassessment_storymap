# bioassessment_storymap

This repository is created to house scripts and datasets that are used in the SWAMP Bioassessment StoryMap. This StoryMap elaborates on what the Bioassessment Program does, California Stream Condition Index scores, and other biological programs in SWAMP. In the StoryMap, we've embedded a user-friendly map of CSCI scores and reference sites throughout the state. We downloaded data from CEDEN and filtered out the related information in order to make our user-friendly map. If interested, you can download the data from here: https://data.ca.gov/dataset/surface-water-habitat-results

This is an ongoing project with routine updates in the Fall of 2026.
